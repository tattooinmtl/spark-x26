# Plan

For anything bigger than a single edit, write the steps down before starting.

1. Restate the goal in one sentence and list the files it touches.
2. Break it into steps that each end in a checkable state.
3. Do one step, verify it, then start the next.
4. Keep the plan short. Three to six steps. Long plans drift.

If a step turns out to be wrong, stop and re-plan instead of pushing through.
Finish with `finish` and a summary of what changed and what was verified.

# Audit 2026-11-05

> Summary: Bugs, security issues and TUI gaps found in the code audit.

## Context
Read-only audit of dev `C:\models\spark26` and prod `C:\Users\ThePa\.spark-code26`, commit `bc5d2f0`. Dev and prod differ only in CRLF line endings.

## Details

| id | where | bug |
|---|---|---|

| B2 | tui.py:424,436 | `history or []` + `if ... history and` → history never records. |
| B3 | spark_agent.py:1712 | footer runs `git rev-parse` on every keystroke → typing lag. |

| B10 | tui.py / spark_agent.py:1888 | **reported by user**: title and prompt mixed at the top once the app loads. Cause not confirmed — needs a screenshot. Suspects: relative cursor moves of the first prompt draw after server startup lines; banner width vs terminal width. |

### Agent / session
- S1 `/clear` keeps `session_id` → next save overwrites the previous session.
- S2 git tools walk up to the parent repo when the workspace has no `.git`.
- S3 `load_session` does not rebuild the system prompt.
- S4 system prompt never says the shell is cmd.exe (model ran `head`).
- S5 `--max-tokens 1024` too small for thinking (same root as B9).
- S6 ↑ token stat counts only uncached tokens.
- S7 history re-rendered after `.strip()`/re-serializing → probable full re-prefill every step on this SWA model (see KV note).

### Security
- H1 `run_command`: no jail, no approval, bypassable denylist.
- H2 writes/edits: no approval.
- M1 `Workspace.resolve` uses `normpath` (symlink/junction escape).
- M2 git commands built as shell strings.
- OK: web tools (SSRF guard on every redirect), server on 127.0.0.1, kill-on-close job object.
